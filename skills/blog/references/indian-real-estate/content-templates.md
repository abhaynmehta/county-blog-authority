# Indian Real Estate Content Templates

## 1. Locality Guide
**Intent:** Buyer researching a specific area
**Example:** "Sector 150 Noida: Complete Buyer's Guide"

### Required sections:
- Location and connectivity (distances from official sources only)
- Infrastructure: operational, under construction, approved, proposed (clearly labeled)
- Social infrastructure: schools, hospitals, retail (name specific ones)
- Housing supply: project landscape, segments, price range
- Employment hubs and commute corridors
- Buyer profile (who is this area for?)
- Investment considerations with risks
- How to verify claims (RERA portal, development authority)

### Do NOT:
- Template the same content for different sectors with name substitution
- State travel times as guaranteed
- Declare a winner among localities

## 2. Project Content
**Intent:** Buyer evaluating a specific project
**Example:** "Clove County Sector 151: What Buyers Should Verify Before Booking"

### Required sections:
- Developer and promoter (with RERA verification link)
- Location and micro-market context
- Configurations with carpet area (from RERA/sanctioned plan, not brochure)
- Amenities with status labels (planned/operational)
- RERA registration and possession timeline
- Construction status with evidence
- Pricing context (if available from official sources)
- What to verify: BBA, sanctioned plan, possession clause, payment schedule
- Comparable projects (for context, not to declare winners)

## 3. Investment Guide
**Intent:** Investor evaluating a market or segment
**Example:** "Noida Real Estate Investment in 2026: Evidence-Based Analysis"

### Required sections:
- Market context with institutional data (CBRE, ANAROCK, NHB)
- Infrastructure impact (only verified projects with status)
- Supply-demand analysis with sources
- Historical price trends (with data source and methodology note)
- Total acquisition cost analysis (not just per-sqft)
- Rental ecosystem (with actual rental evidence)
- Risk factors and considerations
- Exit strategy considerations

### CRITICAL rules:
- Separate verified historical data from forward-looking interpretation
- NEVER state "guaranteed appreciation" or "assured returns"
- State limitations: past performance ≠ future results
- Include total cost: stamp duty, registration, GST, maintenance, fit-out

## 4. Comparison Content
**Intent:** Buyer comparing options
**Example:** "Noida vs Gurgaon for Homebuyers: 2026 Comparison"

### Required sections:
- Comparison criteria (standardized, not arbitrary)
- Data for each option (from same source tier)
- Pros and considerations for each (not pros and cons that declare a winner)
- Buyer profile matching: "Choose X if you prioritize..."
- Verification links

### Do NOT:
- Declare arbitrary winners
- Compare using different data sources for each option
- Use comparison to push one developer's project

## 5. Infrastructure Impact
**Intent:** Buyer/investor researching infrastructure development
**Example:** "Noida International Airport: Impact on Sector 150-151 Real Estate"

### Required sections:
- Infrastructure project details (from official authority)
- Current status: operational/under construction/approved/proposed
- Timeline with source
- Connectivity changes (factual, not speculative)
- Historical impact of similar infrastructure (with evidence)
- Market response (from institutional data)
- Risk factors: delays, scope changes, secondary effects

### CRITICAL:
- NEVER present proposed infrastructure as completed
- State the official source for every timeline
- Distinguish operational from announced

## 6. Homebuyer Education
**Intent:** First-time buyer learning the process
**Example:** "RERA Explained: How to Verify Any Developer in Uttar Pradesh"

### Required sections:
- Clear, step-by-step process
- Official portal links and verification steps
- What documents to check (BBA, sanctioned plan, OC/CC)
- Red flags to watch for
- Checklist format preferred
- Legal references (RERA Act sections where relevant)

### Do NOT:
- Make this a disguised sales pitch
- Skip the verification steps that might reveal issues
- Present RERA registration as a quality guarantee
