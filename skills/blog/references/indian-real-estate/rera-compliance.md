# RERA Compliance Rules for Content

## What is RERA
The Real Estate (Regulation and Development) Act, 2016 regulates the Indian real
estate sector. Every state has a RERA authority. For County Group projects:
- UP RERA: https://www.up-rera.in (Noida, Greater Noida, Ghaziabad)
- Delhi RERA: For Delhi projects
- Haryana RERA: https://haryanarera.gov.in (Gurgaon projects)

## Content Rules

### RERA registration ≠ endorsement
- RERA registration is a regulatory REQUIREMENT, not a quality seal
- Never write: "RERA approved project" (implies government endorsement)
- Write: "RERA registered project" with registration number

### Verify before publishing
For every project mentioned, verify on the RERA portal:
1. Registration number and validity
2. Registered promoter name (may differ from marketing brand)
3. Registered completion/possession date
4. Project status
5. Number of units and towers
6. Sanctioned plan details

### Section 13 — advance payments
- Promoter cannot accept more than 10% of apartment cost as advance
  without a registered Agreement for Sale
- Relevant when writing about booking or payment processes

### Possession vs completion
- RERA "completion date" = date by which the project must be completed
- Actual possession may differ (builder needs OC/CC first)
- Never conflate the two

### Claims that need RERA evidence
| Claim | Required evidence |
|-------|-------------------|
| Number of units/towers | RERA filing |
| Land area | RERA filing / sanctioned plan |
| Possession date | RERA registered date |
| Project status | RERA portal current status |
| Promoter name | RERA registration |
| Configurations | RERA filing / sanctioned plan |
| Carpet area | RERA filing (not brochure super built-up) |

### Investment-related content
The RERA Act's intent is to protect homebuyers. Content must:
- Distinguish facts from forecasts/opinions
- Never guarantee returns, appreciation, or rental income
- State that investment decisions involve risk
- Reference historical data with source and methodology
- Note that past performance does not indicate future results

## UP RERA Portal — How to Verify
1. Go to https://www.up-rera.in
2. Search by project name, promoter name, or registration number
3. Check: registration status, promoter details, project details
4. Download: Certificate, project layout, quarterly progress

Always link to the specific project's RERA page when making project claims.
